# «Напомни»: концепция оформления

Два направления, у каждого своя законченная система. В `concept.html` 1 CSS px = 1 dp, рамка телефона 360×780.
Шаг сетки 4 dp. Новых библиотек нет: только Compose foundation и material3. Барабан сделан на `LazyColumn` со снапом.
Всё, что выходит за `MaterialTheme.colorScheme` (выходные, акцент-текст, фон активного блока, подсветка), лежит в своём
`NapomniColors` через `staticCompositionLocalOf`.

**Рекомендую A «Полночь и латунь».** Из двух направлений только оно даёт и «солидно», и «богато»: тёплая бумага,
глубокий синий, латунь и антиква в цифрах. B строже и дешевле в реализации, потому что обходится без своего шрифта. Зато он легко
скатывается в «обычный финтех».

## A. «Полночь и латунь»

Тёплая бумага цвета слоновой кости, глубокий полуночно-синий и латунь вместо гравировки. Настроение — спокойная роскошь частного
банка и записной книжки в кожаном переплёте. Латунь идёт только на линии, метки и полосу барабана, сплошных
золотых заливок в светлой теме нет.

### Форма, отступы, тени

- Скругления: лист 22 dp сверху; карточка блока, группа списка, сводка и предупреждение 12; чип, день и сегмент 10; кнопка 12;
  FAB круглый; переключатель — капсула; виджет 22 (на Android 12+ `system_app_widget_background_radius`).
- Поля: лист 12 dp по бокам, внутри карточек 12–14. Между блоками 10, между чипами 6.
  Высоты: кнопка 52 (малая 38), чип 38, день 56, строка барабана 40, строка с переключателем от 52, строка списка от 64.
- Тени почти не нужны, держится всё на обводках 1 dp. Тени есть только в трёх местах: у активного блока (кольцо 3 dp из латуни с прозрачностью 16% плюс
  `0 8 24` с основным цветом на 10%), у FAB (elevation 6) и у листа (системная).

### Компоненты

- **Шапка мастера.** Сверху ручка 36×4 цвета outline. Под ней надстрочник «ШАГ 1 ИЗ 2» акцент-текстом и заголовок шага.
  Справа круглая кнопка ✕ 36 dp в обводке. Индикатор шага — два отрезка по 2 dp на всю ширину с зазором 6:
  текущий и пройденный латунные, будущий в обводке.
- **Карточка блока**:
  - *обычный*: поверхность, обводка `outlineVariant`, метка капсом вторичным цветом, маркера нет;
  - *активный («сюда дальше»)*: обводка латунью 1 dp, фон активного блока, кольцо-свечение, слева латунная планка 3 dp
    (с отступом 14 dp сверху и снизу), перед меткой латунный ромб 7 dp. Метка в акцент-тексте, справа подсказка
    «выберите время»;
  - *заполненный*: вид обычного, перед меткой точка основного цвета, справа значение PT Serif и ✓ акцент-текстом.
    Содержимое не сворачивается, чтобы выбор можно было поменять.
- **Чип.** *Обычный*: поверхность, обводка `outline`. *Выбран*: заливка основным, текст на основном.
  *Недоступен* (прошедшие «За 3 дня»…): прозрачный, альфа 0,42, не нажимается.
  *Выходной*: текст цвета выходных и контур выходного дня. *Выходной выбран*: заливка основным, текст «выходные на основном».
  В мультивыборе («В какие дни») перед текстом выбранного чипа стоит ✓.
- **Кнопки.** *Основная*: заливка основным, 52 dp, скругление 12, внутренний блик сверху 1 dp (белый 8%).
  *Вторичная* («‹ Назад»): прозрачная с обводкой `outline`. *Текстовая* («Настроить ›», «‹ изменить», «Другая дата ›»):
  акцент-текст без фона, высота 40. *Отключённая*: альфа 0,38. *«Далее» в активном состоянии*, когда время выбрано:
  двойное кольцо — 3 dp цвета фона и 1,5 dp латуни.
- **Поле «Что напомнить».** Без рамки. Над ним метка капсом, под текстом линия 1 dp `outline`, в фокусе 1,5 dp основного цвета,
  курсор латунный. Распознанное время («завтра в 10») выделяется фоном подсветки со скруглением 4 и тем же цветом текста.
- **Барабан** (часы : минуты). Видно 5 строк по 40 dp, в шаге 2 — 3 строки. Полоса выбора идёт на всю ширину блока:
  фон полосы и две латунные линии по 1 dp сверху и снизу, как окошко даты на циферблате. Выбранное значение 28 sp
  с непрозрачностью 1; ±1 строка — масштаб 0,74 и альфа 0,55; ±2 — 0,60 и 0,28. Края колонки затухают градиентной маской
  (прозрачно → 28% → 72% → прозрачно). Двоеточие латунное, стоит на месте. Часы выровнены к двоеточию справа, минуты слева.
  Часы идут без ведущего нуля (9, 19), минуты двузначные с шагом 5.
- **Календарь месяца** (раскрывается из «Другая дата ›»). Шапка «Октябрь 2026» PT Serif 17, стрелки ‹ › текстовыми кнопками.
  Строка дней недели «Пн … Вс», сб и вс цветом выходных. Ячейка 38 dp, числа PT Serif 15. *Сегодня* обведено кольцом
  1,5 dp основного цвета. *Выбранный день* — круг с заливкой основным. *Прошедшие* с альфой 0,4. *Точка* 4 dp
  латунью под числом означает, что на этот день уже есть напоминание.
- **Сегмент «Как напомнить»** («Звук / Вибро / Тихо / Будильник»): общая рамка `outline` со скруглением 10, внутри разделители 1 dp,
  выбранный сегмент залит основным.
- **Переключатель** 44×26. Выключен: прозрачная дорожка с обводкой `outline`, ручка цвета `outline`.
  Включён: дорожка основного цвета, ручка «текст на основном». Анимация 180 мс.
- **Строка «Мелодия — Восход ›».** Высота 48, слева «Мелодия», справа «Восход ›» вторичным цветом, «›» латунью.
  **Меню выбора мелодии** открывается модальным листом поверх мастера. В шапке «Мелодия» PT Serif 20,
  список строк по 52 dp. Слева радио: латунное кольцо 18 dp и точка 8 dp у выбранной. Справа «▶» —
  проба на 3 с, во время пробы кнопка становится «■». Внизу основная кнопка «Готово». Выбранная строка
  дополнительно идёт на вторичной поверхности.
- **Карточка-предупреждение о разрешении.** Фон карточки-предупреждения, обводка, латунная планка слева 3 dp.
  Заголовок Roboto Medium 15, пояснение 13,5 вторичным, малая основная кнопка «Разрешить» справа внизу.
  Цвет ошибки сюда не идёт: это просьба, не авария.
- **Строка списка.** Слева колонка времени 70 dp (PT Serif 18). «весь день» набирается Roboto 13 вторичным.
  У «Вс 18 окт / 19:00» две строки, дата цветом выходных. Справа название Roboto Medium 15,5 и подпись 13
  вторичным, «✓» акцент-текстом. Группа — карточка поверхности с разделителями 1 dp. Заголовок группы
  («СЕГОДНЯ») — метка капсом с волосяной линией до правого края.
- **«Прошедшие (12)».** Строка на вторичной поверхности со скруглением 12, текст вторичный, справа «›».
- **FAB «+».** Круг 58 dp основного цвета, внутреннее латунное кольцо 1 dp с отступом 2 dp, плюс 22 dp линией 1,8.
- **Экран будильника.** Всегда тёмный: ночью белый экран слепит. По центру циферблат 280 dp из 60 латунных рисок,
  часовые длиннее и ярче, на 12 часах ромб. Внутри «19:00» PT Serif 76. Ниже «вс 18 окт» цветом выходных,
  название PT Serif 26, «повтор через 5 мин…» вторичным с медленно пульсирующей латунной точкой.
  Внизу «Готово»: 64 dp, заливка латунью, скругление 16. Под ней в ряд «Отложить 10 мин» и «Отложить 1 ч» с обводкой.
- **Тёмная тема.** Основной цвет становится латунным: выбранные чипы и главные кнопки — латунь с тёмным текстом.
  Карточки синие, обводки `#2D3950`, выходные светло-коралловые. Вся структура та же.

## Общее для обоих направлений

### Состояния блоков и порядок шагов мастера

Шаг 1 идёт так: текст → «Через» или «День» → «Время события» → «Далее». Шаг 2 так: «В какие дни» → «Во сколько» →
«Как напомнить» → «Напомнить».

1. После выбора текущий блок становится *заполненным*. Через 120 мс следующий блок по порядку становится *активным*,
   и одновременно идёт прокрутка к нему. Выбор в «Через» сразу показывает «Напомнить» и «Настроить ›»
   и активными больше ничего не делает.
2. Смена цветов и обводки идёт через `animateColorAsState` и `animateDpAsState`, `tween(220, FastOutSlowInEasing)`.
3. Активный блок всегда один. Если пользователь сам ткнул в другой блок, активным становится тот.

### Прокрутка к следующему блоку

- `scrollState.animateScrollTo(target, tween(durationMillis = 420, easing = CubicBezierEasing(0.2f, 0f, 0f, 1f)))`.
- `target` — наименьший сдвиг, при котором блок виден целиком с полем 16 dp снизу. Если блок выше видимой
  области или не помещается, его верх выравнивается на 16 dp от верха области прокрутки. Координаты берутся из
  `onGloballyPositioned`, позиция блока внутри `Column(Modifier.verticalScroll(scrollState))`.
- Пока палец на экране (`scrollState.isScrollInProgress`), автопрокрутки нет.
- При `ANIMATOR_DURATION_SCALE == 0` (анимации выключены) прокрутка идёт через `scrollTo` без анимации.
- В `concept.html` клик по дню или кнопка «Показать переход» воспроизводят именно эту кривую и длительность.

### Барабан на LazyColumn

- Два `LazyColumn` (часы и минуты) шириной 64 dp. `itemHeight = 40.dp`,
  `contentPadding = PaddingValues(vertical = itemHeight * (rows - 1) / 2)`,
  `flingBehavior = rememberSnapFlingBehavior(listState)`.
- Выбранный индекс: `derivedStateOf { listState.firstVisibleItemIndex + if (firstVisibleItemScrollOffset > halfItemPx) 1 else 0 }`.
  Значение уходит наружу, когда `!listState.isScrollInProgress`. При смене индекса —
  `HapticFeedbackType.TextHandleMove`.
- Масштаб и альфа у каждого элемента считаются в `graphicsLayer {}` по расстоянию от центра, которое берётся из
  `layoutInfo.visibleItemsInfo`: 0 → 1/1, 1 → 0,74/0,55, 2 → 0,60/0,28.
- Затухание: `Modifier.graphicsLayer(compositingStrategy = CompositingStrategy.Offscreen).drawWithContent { drawContent();
  drawRect(Brush.verticalGradient(0f to Transparent, .28f to Black, .72f to Black, 1f to Transparent), blendMode = BlendMode.DstIn) }`.
- Полоса выбора рисуется `Box` позади колонок по центру. В A это фон с линиями 1 dp сверху и снизу через `drawBehind`, в B — фон со скруглением 10.
- Кольцевая прокрутка часов: 24 × 1000 элементов, старт с середины, значение `index % 24`.
- Доступность: `semantics { contentDescription = "19 часов"; stateDescription = … }`, плюс пользовательские действия
  «больше» и «меньше» для TalkBack.

### Выходные

Сб и вс выделяются цветом выходных везде: на кнопках дней, в календаре (и в заголовке дней недели), на виджете,
в итоговой строке шага 2, в колонке даты списка и на будильнике. Цвет вычисляется по `DayOfWeek`, не по подписи.
